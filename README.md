# Vamos juntos · viajes.pausaconjesus.com

Página del subdominio que muestra la app de traslados de Pausa con Jesús.
La app y los datos viven en Google Apps Script + Google Sheets; aquí solo está la "ventana" con la dirección propia.

- `index.html`: abre la app (URL `/exec` de Apps Script) y pasa los enlaces `?t=` (viaje), `?d=` (conductor), `?r=` (reserva) y `?view=admin`.
- `og.jpg`: imagen que se ve al compartir el enlace en WhatsApp.
- `CNAME`: dominio propio para GitHub Pages.
